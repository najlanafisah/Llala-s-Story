# Llala's Story

My first personal website project, created while I was beginning to learn web development. This project represents my early exploration of building web pages using HTML, CSS, and JavaScript.

## Features

- Personal website interface
- Custom page styling and layout
- Basic JavaScript interactions
- Static web page structure

## Tech Stack

- **HTML5**: Web page structure
- **CSS3**: Styling and layout
- **JavaScript**: Basic interactivity

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/Llala-s-Story.git
   cd Llala-s-Story
   ```

2. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
